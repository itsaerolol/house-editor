## UI: game build mode

- Full-bleed world, no docked panels. Floating dark glass HUD.
- Mode dock: Explore, Build, Decorate, Walk (X, B, C, P), spring thumb.
- Floor elevator on the left (2, 1, B, All); tap active floor to isolate.
- Bottom shelf: Build tools with style cards; Decorate catalog with rendered thumbnails for all 56 items.
- Inspector appears as a card only on selection. Floors, layers and settings live in slide-out drawers.
- HIG: 30 px desktop targets, 44 px on touch, focus rings, contrast raised on secondary text.
- bubblyui: rise/pop springs as CSS linear(), 180 ms ease-in exits, staggered shelf cards, reopen cancels exit, Reduce Motion falls back to fades.

## Performance pass (measured, then fixed)

Profile before (main thread, starter house): texture painting 4.8 s, furniture geometry 1.9 s, detailed doors and windows 1.1 s, all blocking; the canvas re-rendered every frame even when idle, shadows re-rendered every frame, every mouse move re-rendered the whole HUD.

| technique | where | effect |
|---|---|---|
| Worker pool (2-4 module workers, inlined) | textures, furniture, door and window trim | main thread JS at load: ~7.8 s to ~0.15 s |
| IndexedDB tile cache keyed by a hash of the painters | textures | repeat visits skip painting |
| Placeholder then in-place swap | textures (flat colour first), openings (plain frame first), furniture | HUD in 0.3 s, house appears progressively |
| Batched arrivals (one commit and one frame per 100 ms) | all streamed results | loading never floods React or the GPU |
| Opening build cache by style and size | doors, windows | repeats placed, not rebuilt |
| `frameloop="demand"` (walk stays continuous) | canvas | zero GPU work when nothing changes |
| Baked shadow map (`autoUpdate=false`, dirty on scene change only) | shadows | orbiting and walking reuse the map |
| Regress while moving: AO pass paused, DPR eased on High | post, canvas | AO and full DPR return at rest |
| three-mesh-bvh accelerated raycast, trees built at idle | hover, click, walk aim | picking no longer scans every triangle |
| Hover only renders through React; drags force frames | pointer moves | moving the mouse over a still scene is free |
| Shallow store reads (`useApp`), cursor kept out of the store | HUD, cards, dialogs | panels re-render only when their data changes |
| Parallel shader warm-up (`compileAsync`) for used variants, fade-in | first frame | no shader-link stalls when furniture arrives |
| `checkShaderErrors` off in production | renderer | no sync GPU round trip per program |

## Lists

- Material fields are an image picker: real texture sample chips (83, rendered at build), search, keyboard, alphabetical.
- Walk finish palette: chips, families and materials alphabetical.
- Decorate shelf, categories, house styles, door and window cards, object list groups and entries, selects: alphabetical.
- Object list shows a furniture thumbnail per row; the furniture card shows the item's image.
- Exception: the floor elevator stays in building order (top to bottom), since it mirrors the house.

## Home screen and saved houses
- IndexedDB library (`src/store/library.ts`): one record per house with JSON, rooms/items counts, card picture. Autosave writes there (600 ms debounce, also when the page is hidden) plus a quick localStorage copy for fast launch.
- Home screen (`src/ui/Home.tsx`): Continue hero, houses grid, New house (starter or blank lot), Import, per-house Rename, Duplicate, Export file, Delete (confirm).
- Card pictures: a render of the 3D view when leaving for Home; floor-plan drawing otherwise.
- Export uses the share sheet on phones (Save to Files), a download elsewhere.
- PWA: manifest shortcuts (New house, My houses), cache `farmhouse-v2`, persistent storage requested.

## Rugs, roof fit, Iso world
- Rugs and mats: own material with a stronger depth bias than the floor finish (-5 vs -2), 14 mm pile, 0.8 to 2.4 mm lift per rug; perspective near plane 0.3, walk near plane 0.1.
- Roofs sit on the outer wall faces: lifted by reach x pitch so wall tops stay inside the slab; gable infill is a solid panel flush with the wall's outer face.
- Iso shares the 3D world: painted sky, haze, grass to the horizon (no cut-away skirt).
- Walk controls card: 8 s auto close with a countdown bar and an X; a Controls button brings it back.
